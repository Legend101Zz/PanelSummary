# v0.2 documents

Index of the files in `docs/v0.2/`. These pages record the v0.2 build. Each track page names what it
built, how it verified it and what stays open. The design is in `docs/design/` (index:
`docs/design/README.md`). The decisions D21 to D28 are in `docs/decisions.md`. The v0.1 notes are in
`docs/launch/README.md`.

| `GATES.md` | The gate results (CI, UI, quality, hold-out books, the final journey, spend) and where the evidence is. |
| `API-GAPS.md` | The API that the new screens need and what the backend lacked. |
| `S1-backend.md` | Track S1: scope (sections or a PDF page range), plan review (D24), `GET /status` (D25), timings. |

| `Q1-renderer.md` | Track Q1: renderer 0.6.0, story vocabulary and camera push-in (D28). |
| `Q2a-writer-checks.md` | Track Q2a: the writer checks and their calibration rule (D26). |
| `Q2b-continuity.md` | Track Q2b: places, panel flags and minor figures (D21 to D23). |
| `E1-holdout-books.md` | Track E1: two hold-out test books that the tuning never saw. |
