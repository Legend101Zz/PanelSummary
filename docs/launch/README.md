# Launch documents

Index of the files in `docs/launch/`. These pages record the v0.1 launch work (tracker #17).
Each track page names its branch, its tests and what stays open. The model policy is in
decision D13 in `docs/decisions.md`.

| File | What it is |
|---|---|
| `V0.1-ULTRACODE-PROMPT.md` | The launch plan and the prompt for the orchestrating session. |
| `CI.md` | What `ci.yml` runs, and how to start, limit, download and judge a live run. |
| `EVAL.md` | The quality judge harness: export, draw, judge panel, aggregate, baseline. |
| `T0-model.md` | Track T0: `MiniMax-M3.1-Flash-Preview` registered and selectable per goal. |
| `T1-continuity.md` | Track T1: character state per page, claims fully shown, craft grammar audit. |
| `T2-renderer.md` | Track T2: renderer 0.4.0, props, scale, places, captions, story-state looks. |
| `T3-scope.md` | Track T3: size limits (D19), preflight, honest latency (D20). |
| `T5-product.md` | Track T5: the frontend surface (estimate, progress, failure wording). |
| `W2-renderer.md` | Track W2: renderer 0.5.0, legibility of heroes, key props, tails and settings. |
| `F1-dense-page.md` | Track F1: the dense-page failure loop and the repair hints. |
| `F2-integration.md` | Track F2: the integration of the backend and frontend tracks. |
| `README.md` | This index. |

Other pages: `README.md` in the repository root (run it, verify it, limits),
