### Journey: Generate a manga adaptation of a book (the product)

- **User and goal:** Owner/reader uploads a PDF and wants a readable, source-grounded manga
  adaptation of it.
- **Supported entry:** `POST /upload` → `POST /books/{id}/manga-projects` →
  `POST /manga-projects/{id}/book-understanding` → `POST /manga-projects/{id}/build`
  (or `.../generate-slice` per slice), driven from the Manga V2 Lab UI.
- **Preconditions and representative data:** Book status `parsed` or `complete`; book
  understanding present. Representative data: "Who Moved My Cheese" — the reference book for
  every measured number in this repo.
- **Expected visible outcome:** `MangaPageDoc.rendered_page` records readable at
  `/books/{id}/manga/v2`.
- **Current authority:** **v1 lane** — `build_v2_generation_stages()`,
  `backend/app/services/manga/generation_service.py:212`. `Code-resolved`.
- **Desired authority:** agentic lane, per issue #15 Phase 4. **Proposed, owner-gated.**
- **Observability and receipt:** `JobStatus` polled via `GET /status/{task_id}`;
  `/tmp/panelsummary-celery.log`; `MangaSliceDoc.quality_report` + compact LLM traces;
  `continuity_ledger` and `last_failure` for informed resume.
- **Proof obligations for any future cutover:**
  1. Runtime-path receipt naming the lane, SHA, resolved flags, and stages executed.
  2. Ordinary browser journey — upload → build → read — completing on the agentic lane.
  3. Negative reachability: `build_v2_generation_stages()` no longer reached from `/build`.
  4. Human side-by-side judging preferring agentic output over the v1 baseline.
- **Forbidden observations:** any agentic-lane claim supported only by a shadow-lane row;
  any "generated by v2" assertion where `agentic_manga_pipeline_v1` was false; any cost
  figure not tied to a persisted `ModelReceipt`.
- **Human acceptance:** owner judging. The 2026-08-09 judging found v1's defects to be
  speaker attribution, illegible sprite compositing, filler sub-panels, and missing
  character intros.

### Journey: Read the generated manga

- **User and goal:** Read the adaptation page by page.
- **Supported entry:** `/books/{id}/manga/v2` (v1 lane, active).
- **Alternate entry:** `/books/{id}/manga/v2lane` — agentic-lane reader, gated by
  `NEXT_PUBLIC_MANGA_V2_LANE_READER=1`, renders an explanatory panel when off.
  `frontend/app/books/[id]/manga/v2lane/page.tsx:3-9`.
- **Expected visible outcome:** laid-out pages with panels, bubbles, sprites, and art;
  empty state when `rendered_page` is missing.
- **Current authority:** v1 reader over `MangaPageDoc.rendered_page`.
- **Desired authority:** agentic reader over `GET /manga-projects/{id}/v2/pages`
  (`backend/app/api/routes/manga_v2_reader.py:97`). Proposed (Gap 9, nice-to-have).
- **Observability and receipt:** browser screenshots; the repo convention is that every
  visual renderer change needs before/after screenshots (`CLAUDE.md`).
- **Proof obligations:** visual evidence at desktop and one narrow viewport; legacy pages
  carrying only `gutter_grid` must still render via the fallback path.
- **Forbidden observations:** a legacy stored page silently failing to render; sprite layers
  or bubble placements dropped without a warning.

### Journey: Generate a whole book through the agentic lane

- **User and goal:** produce a complete multi-scope manga adaptation via the new architecture.
- **Supported entry:** **none.** Script-only: `backend/scripts/whole_book_wmc_s8.py`.
  No route, no Celery task, no UI. `Code-resolved` — grep confirms `WholeBookChainExecutor`
  has no non-test, non-script caller.
- **Preconditions:** book normalized into source units + scopes;
  `use_compiled_context=true`; agent workers running (`:8788`/`:8789`) and broker (`:8010`).
- **Expected visible outcome:** agentic-lane pages readable at `/manga/v2lane`.
- **Current authority:** none — this journey does not exist as a product path.
- **Desired authority:** a `lane` option on `POST /manga-projects/{id}/build` plus a Celery
  task reporting into `JobStatus` like v1 (issue #15, Gap 3).
- **Observability and receipt:** `chain_outcome.json` (plan hash, per-scope status, reused
  stages, per-lane USD, remaining budget); per-call `ModelReceipt`/`ProviderReceipt`;
  optional verbatim seam dumps via `agent_seam_raw_dump_dir`.
- **Proof obligations:**
  1. One scope completing direction → page-writing → thumbnails → page-art in a single chain
     (**never achieved** — `docs/evidence/session8-golden-run/chain_outcome.json` records
     `stopped_failure` at the thumbnail stage).
  2. Multi-scope run with rolling canon merge.
  3. Kill-and-resume mid-book with zero duplicate paid calls (Gap 7 — proven against stubs
     in `backend/tests/test_whole_book_v2.py`, never live).
  4. Spend within the granted budget, preflight refusing rather than overspending.
- **Forbidden observations:** any scope starting when its projected spend exceeds the
  remaining budget; a re-run double-merging memory; a paid stage re-charged on resume.
- **Human acceptance:** blocked on Gap 1 (thumbnail model mode) — an owner pricing decision.
